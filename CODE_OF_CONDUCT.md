# Code of Conduct

## Our commitment
Atlas aims to be a respectful learning and contribution space. Participants should communicate clearly, assume good faith, and focus criticism on code and ideas rather than people.

## Expected behavior
- Be respectful and constructive.
- Provide actionable technical feedback.
- Respect privacy and do not publish credentials or user data.
- Follow provider terms and applicable content rights.
- Report security issues privately.
- Acknowledge others' contributions.

## Unacceptable behavior
- Harassment, discrimination, threats, or personal attacks.
- Publishing secrets, personal information, or private conversations without permission.
- Malicious code, credential theft, or unauthorized access.
- Requests or contributions intended to bypass authentication, DRM, paywalls, or access controls.
- Deliberate disruption of project services.

## Enforcement
Project maintainers may edit, reject, or remove contributions and may restrict participation for behavior that violates this policy. Report concerns privately through the maintainer's GitHub profile.

This policy applies to issues, pull requests, reviews, and project-related discussions.
