# 🆘 Support

Atlas is an educational prototype maintained on a best-effort basis. It is not secure account-management software.

## Before asking
Read the README, installation guide, FAQ, and troubleshooting guide. Reproduce the issue with a disposable local database and synthetic data.

## Bug reports
Use the GitHub bug template and include:
- Node.js/npm versions.
- Route and HTTP method.
- Reproduction steps.
- Expected and actual behavior.
- Sanitized logs and screenshots.

Never post database connection strings, passwords, tokens, cookies, real email addresses, or user records.

## Feature requests
Use the feature request template. Explain the user problem and include security/privacy implications for account, session, or database features.

## Security issues
Do not create a public issue. Follow SECURITY.md and report privately.

## Support boundaries
No SLA or production support guarantee is offered. External database/network configuration may be outside repository control.
