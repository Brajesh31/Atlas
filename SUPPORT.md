# Support

Atlas is an educational prototype and is maintained on a best-effort basis.

## Before asking for help

Check the [README](README.md), [installation guide](docs/installation.md), [troubleshooting guide](docs/troubleshooting.md), and [FAQ](docs/faq.md). Never post database connection strings, passwords, tokens, or personal data.

## Questions and bugs

For reproducible bugs and documentation improvements, open a GitHub issue with the Node.js version, operating system, relevant route, expected behavior, actual behavior, and sanitized logs. Use private reporting from [SECURITY.md](SECURITY.md) for security issues.
