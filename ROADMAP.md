# Roadmap

The roadmap is indicative and may change as the prototype evolves.

## Near term

- Move MongoDB configuration to environment variables.
- Add request validation and useful user-facing error pages.
- Add a test suite for route and model behavior.
- Add a real session-based authentication boundary.

## Security hardening

- Hash passwords with a modern password-hashing algorithm.
- Add rate limiting, CSRF protection, secure cookies, and authorization checks.
- Restrict database permissions and document backup and retention practices.

## Longer term

- Separate the demonstration landing page from account management.
- Improve accessibility and responsive behavior.
- Add structured logging and deployment health checks.
