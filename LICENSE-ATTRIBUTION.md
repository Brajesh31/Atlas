# License and asset attribution notes

## Project source
The repository contains an MIT license. Review LICENSE for the exact terms.

## Third-party resources
The application templates reference remote fonts, icons, image assets, and background art. Their use is separate from the repository's source-code license. Before redistribution or production use:
- Identify the origin of each resource.
- Review its license or terms.
- Add attribution where required.
- Replace assets that cannot be used lawfully.
- Avoid hotlinking assets without permission.

## External packages
Each npm dependency retains its own license and notices. The repository MIT license does not replace those obligations.

## Content policy
Do not add copyrighted media or third-party artwork to documentation unless the rights and license are clear.
