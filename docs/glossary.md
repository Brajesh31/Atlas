# 📖 Glossary

| Term | Meaning |
|---|---|
| Atlas app | The Express/EJS application in this repository |
| Express middleware | Function executed in the HTTP request pipeline |
| Route handler | Function that handles a matching HTTP method and path |
| EJS | Embedded JavaScript template engine used to render HTML |
| Mongoose | ODM library used to define models and communicate with MongoDB |
| MongoDB URI | Connection string used by a MongoDB client |
| Request body | Parsed data submitted by a browser form or API client |
| Static asset | CSS, JavaScript, image, or other file served from public/ |
| Session | Server-associated authentication state linked to a client cookie |
| Authorization | Decision about whether an authenticated identity may access a resource |
| Authentication | Verifying a user's identity |
| Password hash | One-way password verifier produced by a password-hashing algorithm |
| CSRF | Cross-site request forgery, a class of unwanted authenticated actions |
| Rate limiting | Restricting request frequency to reduce abuse |
| ADR | Architecture Decision Record |
| Secret rotation | Revoking an exposed credential and replacing it with a new one |
| Least privilege | Granting a service only the permissions it needs |
| Mermaid | Text-based diagram syntax rendered by GitHub Markdown |
| Technical illustration | Diagram explaining architecture, not a UI screenshot |
| Browser screenshot | Genuine image capture of the running application |

## Status vocabulary
- **Present:** source code exists for the described limited behavior.
- **Partial:** important validation, security, or error handling is missing.
- **Not implemented:** no working implementation exists.
- **Target:** future recommendation, not current code.
